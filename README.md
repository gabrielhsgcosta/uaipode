# Uai Pode 🍻

Cardápio digital do Restaurante e Bar Uai Pode.

## 📋 Sobre o projeto

O Uai Pode é um cardápio digital desenvolvido para facilitar a visualização dos produtos oferecidos pelo restaurante, proporcionando uma experiência rápida e intuitiva para os clientes.

## 🚀 Funcionalidades

- Navegação por categorias
- Menu fixo durante a rolagem
- Destaque automático da seção ativa
- Layout responsivo
- Exibição de imagens dos produtos
- Descrição dos itens do cardápio

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
